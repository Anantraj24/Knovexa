# Knovexa

> Intelligent knowledge workspace that transforms static documents into interactive, citation-grounded intelligence.

Knovexa answers not just *where* a file is, but *what* the knowledge contains. Built for students, researchers, developers, and professionals to ingest documents (PDF, DOCX, TXT), perform vector indexing, and interact through provider-independent RAG chat with verified citations.
